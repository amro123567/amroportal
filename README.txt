Amro Academy Platform - static UI prototype (demo data only, nothing is saved)

Open index.html in a browser, or upload this whole folder to any static host
(GitHub Pages, Netlify, Cloudflare Pages, AWS S3 + CloudFront).
Keep the assets/ folder next to the .html files.

Every link opens a page; tabs, toggles, answer choices, time slots and buttons respond
(assets/demo.js shows a short confirmation for actions that need the real backend).

Admin:   Admin-Dashboard, Admin-Students, Admin-Student-Profile, Admin-Finance, Admin-Automations,
         Admin-Practice, Admin-Reports, Admin-Leads, Admin-Settings
Tutor:   Tutor-Calendar, Tutor-Students, Tutor-Session-Log, Tutor-Practice-Results, Tutor-Earnings,
         Tutor-Messages, Tutor-Availability
Parent:  Parent-Home, Parent-Free-Time, Parent-Schedule, Parent-Billing, Parent-Reports, Parent-Messages
Student: Student-Home, Student-Test, Student-Lesson, Student-Homework, Student-Sessions, Student-Scores
